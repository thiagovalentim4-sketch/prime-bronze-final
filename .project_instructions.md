# Prime Bronze - Estúdio de Bronzeamento Artificial

## Visão Geral
Aplicação SaaS para o estúdio de bronzeamento Prime Bronze, localizado em Mesquita-RJ.

## Identidade Visual
- **Cores**: Dourado (#D4AF37, #B8860B), Preto (#0a0a0a), Branco
- **Tema**: Escuro com acentos dourados
- **Logo**: /public/images/logo.jpeg
- **Slogan**: "Seu Brilho, Nossa Paixão"

## Estrutura
### Área Pública (route group `(public)`)
- `/` - Homepage com hero, serviços, galeria, benefícios, CTA
- `/servicos` - Lista de serviços com preços
- `/sobre` - Página institucional
- `/contato` - Contato com mapa e WhatsApp
- `/agendar` - Sistema de agendamento em 4 etapas

### Área Admin (`/admin`)
- `/admin/login` - Login
- `/admin` - Dashboard com estatísticas
- `/admin/agendamentos` - Gerenciamento de agendamentos
- `/admin/servicos` - CRUD de serviços
- `/admin/configuracoes` - Horários e configurações

## Banco de Dados
- User, Service, Booking, BusinessHours, Settings, BlockedSlot
- Serviços pré-configurados: Paredão Duplo (1h, 1h30, 2h), Banho de Lua

- NextAuth v4 com JWT strategy
